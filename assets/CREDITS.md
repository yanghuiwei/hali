## 三、许可条款备注

- **CC-BY 3.0 / 4.0**：可商用、可改编，但**必须署名**（作者 + 来源页链接）。本项目统一在本文件与游戏内「关于/致谢」处署名。
- **CC-BY-SA 3.0**（`bg_dark_winds.ogg`）：除署名外，**改编作品必须以相同许可分发**。仅原样打包播放一般不触发 SA 义务；若对该音轨做剪辑/混音，则成片需以 CC-BY-SA 分发。
- **CC0**：无任何限制，可商用、可改编、无需署名（本项目仍如实登记来源）。
- **OFL-1.1**：可商用、可嵌入，不得单独售卖字体本身；**分发时必须随附 OFL 许可证文本**（后续把 `OFL.txt` 一并放进 `assets/fonts/`）。
- **Harry P**：dafont 页面标注「100% Free / 个人免费，商用需授权」；同时它是**模仿《哈利·波特》官方 Logo 字形的粉丝字体**，用于公开项目的标题存在 IP 风险。当前保留供本地/个人使用，**不用于对外发布物的主标题**。

## 五、使用约定

1. **缺素材永远不崩**：任何素材缺失都必须回退到默认主题/无图/静音，并由 `tests/presentation_test.gd` 断言。
2. **新增素材 = 先在本文件登记，再放进 `assets/`**；`presentation.json` 里出现的路径若无对应登记条目，`presentation_test` 判失败。
3. `assets/` **不使用 Git LFS**：当前总体积约 8MB（音频 12MB 中的主体已在转码后下降），远低于需要 LFS 的量级；若将来单文件 >25MB 再重新评估。
4. 本仓库为 **public** 仓库，请勿放入授权不明或含个人信息的素材（`bg_main.ogg` 是已知且有意识地保留的例外，见第二节）。
